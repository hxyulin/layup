`Fallback.ttf` is a small synthetic test face derived from the bundled IBM Plex
Sans Regular. It retains the `M` glyph and maps U+4E2D to it, so tests can prove
that user font bytes affect CJK advances without shipping a CJK font. It is
renamed Layup Test under the SIL OFL; the source copyright and license records
remain in its name table. See `../../fonts/OFL.txt`.
